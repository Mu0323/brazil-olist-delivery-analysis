# 指标口径

## 分析范围

| 场景 | 分析范围 |
|---|---|
| Tableau 经营概览 | 全部99,441笔已创建订单；用于展示平台总体记录规模 |
| SQL 经营指标 | 排除 `canceled` 和 `unavailable` 的订单 |
| 履约阶段 | 全部已创建订单，按时间字段是否存在判断批准、发货和送达 |
| 延误分析 | 仅包含有实际送达时间的96,476笔订单 |
| 评价分析 | 仅包含有评价分数的订单 |

不同模块的分母不同，因此报告数字不能脱离标签直接比较。

## 核心定义

### 订单数

订单级分析统一按 `COUNT(DISTINCT order_id)` 或一行一订单的事实表计数。

### 真实客户数与购买频次

`customer_unique_id` 才是跨订单的真实客户标识；`customer_id` 是一次订单中的客户记录，不能用于计算复购。

### 商品 GMV

```text
商品 GMV = SUM(order_items.price)
```

不包含运费。含运费订单金额为 `SUM(price + freight_value)`。

### 每单商品 GMV

```text
SUM(商品 GMV) / COUNTD(order_id)
```

Tableau 经营概览按全量已创建订单计算，因此与排除取消、不可用订单后的 SQL 指标可能略有不同。

### 延误与准时

```text
延误 = order_delivered_customer_date > order_estimated_delivery_date
```

使用时间戳直接比较。晚于承诺几个小时但不足完整一天仍属于延误；`delay_days = 0` 不代表按时。

准时率只在有实际送达时间的订单中计算：

```text
准时率 = 准时送达订单数 / 已送达订单数
```

### 好评、差评

- 好评：`review_score >= 4`
- 差评：`review_score <= 2`
- 3分评价既不是好评，也不是差评
- 无评价订单不进入好评率或差评率分母

多评价订单当前按订单内评价平均分聚合，再用于订单级分析。

### 复购率

```text
复购客户数 / 真实客户数
```

复购客户指购买订单数大于等于2的 `customer_unique_id`。

### 预计额外差评风险

```text
延误订单数 ×（延误订单差评率 - 未延误订单差评率）
```

该指标仅用于品类治理排序，不表示延误严格造成的差评数量。
